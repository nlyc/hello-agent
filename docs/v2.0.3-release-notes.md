# agentflow v2.0.3

> Web 控制台可选鉴权（HTTP Basic / Bearer）  
> 测试：**457 passed, 4 skipped** · CI：Python 3.10 / 3.12 双绿

## Added

- **Web 控制台可选鉴权**
  - Basic：`WEBUI_PASSWORD`（配合 `WEBUI_USERNAME`，默认 `admin`），浏览器自动弹出登录框
  - Bearer：`WEBUI_TOKEN`，适用于脚本与 API 调用
  - 两种方式可同时启用；都未设置时保持本地开放
  - 401 响应携带 `WWW-Authenticate`，明确提示客户端应使用的认证方式
  - 凭证使用 `hmac.compare_digest` 常量时间比较，避免时序侧信道
- **启动参数覆盖**
  - `--auth-user` / `--auth-password` / `--auth-token`
  - 优先级：命令行 > Shell 环境变量 > `.env`
- **测试覆盖**
  - Basic 正确凭证放行、错误凭证 401
  - Bearer 正确凭证放行
  - 未配置凭证时保持开放

## Changed

- `.env.example` 增加 `WEBUI_USERNAME` / `WEBUI_PASSWORD` / `WEBUI_TOKEN`
- README 与交付检查补充 Web 鉴权说明
- 协议默认版本号更新为 `2.0.3`

## Fixed

- **Windows 本地 MCP 冷启动偶发超时**：`MCPTool.connect_timeout` 默认由 10s 放宽到 30s；Web 控制台 MCP 发现与 stdio 集成测试同步放宽，避免全量测试负载下偶发 `initialize` 超时

## Security

- 控制台仍只监听 `127.0.0.1`；鉴权是本地控制台的额外一层，公网暴露仍应使用反向代理 + TLS
- 鉴权失败的 POST 会读掉不超过 10MB 的请求体并关闭连接，避免 keep-alive 污染与 Windows 连接重置
- 未配置任何凭证时不启用鉴权，保持本地零配置体验

## Tests

- 全量：**457 passed, 4 skipped**
- 新增 Web 鉴权用例，覆盖 Basic / Bearer / 未启用三种路径

## Quick start

```powershell
# Basic：浏览器访问时自动弹出登录框
$env:WEBUI_PASSWORD = "change-me"
py -3.14 -m examples.web_app
```

```powershell
# Bearer：脚本 / API 调用
$env:WEBUI_TOKEN = "change-me"
py -3.14 -m examples.web_app

curl -H "Authorization: Bearer change-me" http://127.0.0.1:8000/api/status
```

```powershell
# 命令行显式覆盖，同时启用 Basic 与 Bearer
py -3.14 -m examples.web_app --auth-user admin --auth-password change-me --auth-token change-me
```

## Compatibility

- 无破坏性变更；未设置 `WEBUI_*` 时行为与 v2.0.2 相同
- 设置密码后浏览器会要求登录；设置 Token 后 API 客户端需携带 `Authorization` 头
- 鉴权只覆盖 Web 控制台，不影响 MCP / A2A 各自独立的 Token 配置
