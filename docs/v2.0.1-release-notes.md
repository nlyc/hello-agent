# agentflow v2.0.1

> CI 工程化 + 工具调用预算补丁  
> 测试：**454 passed, 4 skipped** · CI：Python 3.10 / 3.12 双绿

## Added

- **GitHub Actions CI**：`.github/workflows/ci.yml`
  - push / PR 到 master 自动运行
  - Python 3.10 / 3.12 矩阵
  - `pytest`、评估数据集 `--dry-run`、三个离线 Demo
- **工具调用预算**
  - `Tool.max_calls_per_run`：单工具单次运行调用上限
  - `ReActAgent` / `FunctionCallAgent` 新增 `max_tool_calls`
  - 预算命中时跳过执行，并在 Observation 中提示基于已有信息回答

## Changed

- `ToolCallCollector` 忽略 `budget_exhausted` / `deduplicated` 事件，避免把跳过误计为实际调用
- 在线工具调用评测默认总预算 2 次，`search_notes` 单工具上限 1 次
- 协议默认版本号更新为 `2.0.1`

## Fixed

- CI 安装改为 `.[dev,rag]`，补齐 `pypdf` / `python-docx`，修复 PDF/DOCX Demo 测试
- 本地 Python 3.12 复现验证：453 passed, 5 skipped

## Evaluation

| 套件 | 结果 |
|---|---|
| 工具调用（12 例） | ReAct **12/12**、FC **12/12**（总预算 2 + `search_notes` 上限 1） |
| 全量测试 | **454 passed, 4 skipped** |
| CI | Python 3.10 ✅ / Python 3.12 ✅ |

无预算时 ReAct 仍在 10–12/12 波动；预算策略是可配置的调用治理，不改变默认 Agent 的通用行为。

## Compatibility

- 无破坏性变更
- 预算参数默认 `None`（不限制）；在线评测默认 2 次
- 新能力仍为显式构造或可选配置
