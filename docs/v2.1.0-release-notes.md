# agentflow v2.1.0

> 评估可信度：扩样 + 三轮采样 + Wilson 区间 + 稳定性/失败分析  
> 测试：**463 passed, 4 skipped**（本地）；CI 状态见 Actions

## Highlights

- 三套基准扩至 **36 工具 / 27 QA / 18 行程**，并保留负基线。
- 新增 `scripts/eval_reliability_v2.py`：重复运行、逐题聚合、Wilson 95% 区间、轮次波动、失败样例。
- 新增 `agentflow/evaluation/aggregate.py`：`aggregate_reports` / `wilson_interval` / 聚合报告渲染。
- 修正 QA 与程序化约束的多个假阴性，避免把排版差异当成事实错误。

## 结果（3 轮 × 全量）

| 系统 | 题目 | 尝试 | 通过 | 通过率 | 95% CI | 单轮均值 ± std | 波动题 |
|---|---:|---:|---:|---:|---|---:|---:|
| 工具调用 `S0_react` | 36 | 108 | 108 | **100.0%** | 96.6% – 100.0% | 100.0% ± 0.0% | 0 |
| QA `S0_rag` | 27 | 81 | 81 | **100.0%** | 95.5% – 100.0% | 100.0% ± 0.0% | 0 |
| QA `S1_context_rag` | 27 | 81 | 81 | **100.0%** | 95.5% – 100.0% | 100.0% ± 0.0% | 0 |
| 质量 `S0` | 18 | 54 | 53 | **98.2%** | 90.2% – 99.7% | 98.2% ± 3.2% | 1 |
| 质量 `S1` | 18 | 54 | 49 | **90.7%** | 80.1% – 96.0% | 90.7% ± 3.2% | 4 |

质量 Judge 均分：S0 **4.213**，S1 **3.861**；约束通过率均 98.2%。

结论：工具调用治理稳定；QA 接近天花板；行程质量上 S0 更稳、Judge 分更高。两组质量区间有重叠，应表述为“更稳/更高”，而非“显著优于”。

- **单测**

## Changed

- QA `contains` 现在同时检查最终答案与去引用正文；`exact_match` 仍只检查最终答案。
- QA 文本归一化支持中文数字/金额、时间、列表分隔符、中英文空格。
- 约束判定支持同行人同义词、`腿脚不便的父亲` 这类描述性否定、`改期/取消/替换`、按逗号/分句判断。
- 地名守卫把 `登` 视为动词，`颐和园登万寿山` 不再被当成未收录地名。
- `RAGPipeline.answer` / `answer_from_hits` 新增可选 `temperature`，在线评估 S0/S1 温度对齐。
- 旅行 MCP server 扩充 14 个城市与新笔记，支撑 36 题工具集。
- 协议默认版本号更新为 `2.1.0`。

## Fixed

- S0 QA 温度曾固定 0.2，与 S1 的 0.7 不一致。
- 多行 RAG 回答的“正文有事实、末行是结论”被误判。
- `腿脚不便的父亲/母亲` 被 4 字符否定窗口误判为未包含。
- `都江堰行程建议改期`、`且都江堰景区步行较长` 被误判为安排都江堰。
- `颐和园登万寿山` 被地名守卫误判为未收录。

## Compatibility

- 无破坏性变更；`temperature` 为可选参数，默认行为保持不变。
- `eval_online_v2.py` 默认温度仍为 0.0；`eval_reliability_v2.py` 默认 0.7。
- 数据集已扩展；v2.0 报告中的 12/9/6 数字保留为历史结果，不与应用当前文件直接对比。
- QA gold answer 采用“可核验关键事实”而非整句，以降低排版差异；该取舍已在 v2.1 报告中说明。

## Quick start

```powershell
# 三轮可靠性评估（36 / 27 / 18）
py -3.14 scripts/eval_reliability_v2.py --suites all --repeat 3 --temperature 0.7 --out .cache/eval_reliability

# 单轮在线对比
py -3.14 scripts/eval_online_v2.py --suites all --limit 36 --temperature 0.7 --out .cache/eval_online_v21

# 全量测试
py -3.14 -m pytest -q
```
