## 6. 风险与备注

- **CI**：`.github/workflows/ci.yml` 在 push / PR 到 master 时运行 Python 3.10 / 3.12 矩阵：pytest、评估 dry-run、三个离线 Demo。
- **Windows 子进程**：MCP stdio 已做读取线程、超时与进程清理；A2A 413 / 401 已读掉小请求体避免连接重置。
- **安全**：Terminal 默认 `shell=False`、拒绝元字符、路径 resolve；A2A 默认 `127.0.0.1`、可选 Bearer、1MB 上限；MCP 只连接显式配置的 server。
- **评估诚实性**：离线报告只给负基线，不把自检基线当作 v2.0 真实能力。
- **数据**：`data/eval/` 为合成/公开旅行语料，不含真实用户信息。
