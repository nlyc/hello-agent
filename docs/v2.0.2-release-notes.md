# agentflow v2.0.2

> MCP HTTP / SSE 传输  
> 测试：**456 passed, 4 skipped** · CI：Python 3.10 / 3.12 双绿

## Added

- **MCP HTTP transport**
  - `MCPHttpTransport(url)`：POST JSON-RPC 到 `/mcp`
  - 支持可选 Bearer Token
- **MCP HTTP/SSE server**
  - `MCPHttpServer(server, host="127.0.0.1", port=0, token="")`
  - `POST /mcp`：JSON-RPC 请求/响应
  - `GET /mcp/sse`：SSE 握手（ready + keepalive）
  - 请求体上限、鉴权、连接关闭保护
- `MCPServer.run_http()`
- 旅行 MCP server 新增 `--http --host --port`

## Tests

- HTTP 往返：tools / resources / prompts
- Bearer 鉴权：无 Token 返回 401
- SSE 握手：读取 `event: ready`
- 全量：**456 passed, 4 skipped**

## Quick start

```powershell
py -3.14 -m examples.mcp_server_travel --http --port 8765
```

```python
from agentflow.protocols.mcp import MCPClient, MCPHttpTransport

client = MCPClient(transport=MCPHttpTransport("http://127.0.0.1:8765/mcp"))
client.connect()
print(client.list_tools())
```

## Compatibility

- 无破坏性变更；stdio 仍是默认传输
- HTTP 服务默认只绑定 `127.0.0.1`
- 完整 StreamableHTTP 的会话/双向流仍未实现
