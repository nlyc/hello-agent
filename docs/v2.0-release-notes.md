# agentflow v2.0.0

> 上下文管线 + MCP/A2A 协议接入 + 评估闭环  
> Tag：`v2.0.0` · Commit：`7a5f953` · 测试：**451 passed, 4 skipped**

## Highlights

- **上下文工程**：`ContextBuilder`（GSSC / 六分区 / 预算压缩）+ `NoteTool` + `TerminalTool`
- **协议接入**：MCP（Tools / Resources / Prompts，stdio）+ A2A（AgentCard / Task / Artifact，异步任务 + SSE 事件）
- **评估闭环**：mini-BFCL AST 匹配、QA 准精确匹配、LLM Judge / Win Rate、行程程序化约束与对比报告
- **新增范式**：`FunctionCallAgent`（原生 Function Calling）
- **Web 控制台**：新增上下文 / 笔记 / 协议 / v2 评估页签
- **独立 Judge**：支持 `EVAL_JUDGE_MODEL` / `EVAL_JUDGE_BASE_URL` / `EVAL_JUDGE_API_KEY`

## Added

- `agentflow/context/`：`ContextPacket`、`ContextConfig`、`BuiltContext`、四类 Source、分区压缩
- `agentflow/notes/`：Markdown + YAML front matter 笔记、`notes_index.json`、`NoteContextSource`
- `agentflow/tools/note_tool.py`、`terminal_tool.py`
- `agentflow/protocols/mcp/`：JSON-RPC over stdio、MCPTool 自动展开、Resources / Prompts
- `agentflow/protocols/a2a/`：AgentCard / Task / Artifact、`A2ATool`、`async_mode` + SSE
- `agentflow/agents/function_call_agent.py`
- `agentflow/evaluation/`：数据集、AST / QEM / Judge / Win Rate、报告、`EvaluationTool`
- `examples/demo_context_engineering.py`、`demo_mcp_travel.py`、`mcp_server_travel.py`、`demo_a2a_travel.py`
- `scripts/eval_v2.py`、`eval_online_v2.py`、`eval_combo_v2.py`
- `data/eval/tool_calling.jsonl`、`itinerary_tasks.jsonl`

## Changed

- `Agent` 新增可选 `context_builder`；不传时保持 v1.x 行为
- `OpenAICompatibleLLM` 新增 `chat_with_tools()`，返回结构化 `tool_calls`
- `RAGPipeline` 拆分 `prepare_hits()` / `answer_from_hits()`，支持锁内检索、锁外 LLM
- Web 控制台新增上下文 / 笔记 / 协议 / v2 评估页签
- README、架构图、API 设计、交付检查更新

## Fixed

- QA 引用覆盖改用 `RAGAnswer.citations` + gold chunk 映射
- Terminal 绝对可执行路径需显式加入白名单，堵住工作区外执行
- MCP 远程工具使用配置的 call timeout，而不是 connect timeout
- Agent 失败轮次回滚 user 消息，避免污染下一轮上下文
- Note 全局 limit；文件名优先于 front matter id
- `tail/head -n 0` 返回空；Judge JSON 支持前导噪声
- Web 413 / A2A 401 关闭连接，避免 Windows 连接重置

## Evaluation

在线模型：`deepseek-flash`；独立 Judge：`dev-s-0.62x`。

| 套件 | 结果 |
|---|---|
| 工具调用（12 例） | ReAct 均值 11/12（区间 10–12）；原生 FC 12/12 |
| QA（9 例） | S0 8/9、S1 7/9、S2 7/9；引用覆盖 1.0 |
| 质量（6 例，独立 Judge） | S0 6/6、S1 6/6、S5 6/6；Judge 3.958 / 3.750 / 3.958 |
| 上下文效率 | 20 轮历史下 504 → 260 tokens，节省 48% |

详见 [`docs/v2.0-eval-report.md`](docs/v2.0-eval-report.md)。

## Compatibility

- **无破坏性变更**：`context_builder=None` 时走 v1.x `MemoryContext` 路径
- 新能力默认关闭或显式构造；新增环境变量均为可选
- 现有 292 个基线测试未修改，全量增至 451

## Known limitations

- ReAct 同工具多变体仍可能过度调用；多次复跑在 10–12/12 波动
- 在线评估样本较小，结论以工程回归为主
- MCP 目前为 stdio 子集，HTTP / SSE / StreamableHTTP 尚未实现
- A2A 支持 SSE 任务事件，暂未实现 Webhook / 推送
- Web 控制台仅本地单用户，无鉴权
